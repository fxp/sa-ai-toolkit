# Query 模板库（按行业 × 部门）

每条 Query 提供"骨架"，使用时把 `{占位}` 替换成企业真实产品/标准/部门名。

---

## 一、通用骨架（适用所有行业）

### 1.1 标书/投标
- 帮我审查 `{标书名}`，重点检查：资质证书有效期、技术参数与招标要求是否一致、商务条款风险
- 对比 `{产品A}` 和 `{产品B}` 的技术参数表，列出差异并标注是否满足 `{招标编号}` 要求
- 根据 `{招标公告URL}`，提取关键评分点 + 截止时间 + 必需资质，生成应标 checklist

### 1.2 设计研发
- `{产品型号}` 的 `{部件}` 在 `{工况}` 下出现 `{现象}`，可能原因 Top5 + 验证方案
- 把 `{标准编号 如 GB/T 6451-2015}` 中关于 `{条款}` 的要求，转成可勾选的设计 checklist
- 检索 `{专利数据库}` 中 `{关键词}` 近5年专利，按技术路线聚类

### 1.3 质量管理
- 这批 `{产品}` 的检测报告中，`{指标}` 偏差超过 `{阈值}` 的样本，按生产线/班次分组统计
- 根据 `{标准}` 给出 `{产品}` 的来料检验项目清单，区分必检/抽检
- 客诉文本批量分类：质量/物流/服务/价格，输出每类Top3根因

### 1.4 合同法务
- 审查这份 `{合同类型}` 合同，标注：付款条款风险、违约责任不对等、知识产权归属、保密期限
- 对比甲方版本和我方修订版，列出所有实质性变动 + 风险评级
- 根据 `{法规}` 检查 `{合同}` 是否合规

### 1.5 生产制造
- `{设备型号}` 报警代码 `{代码}`，可能原因 + 应急处置 + 备件清单
- 工艺参数 `{参数表}` 异常波动分析，给出根因假设和验证步骤
- 根据订单 `{订单号}` 的BOM和当前库存，生成采购紧急度排序

### 1.6 知识管理
- 把这次故障处理过程，按"现象-诊断-处置-验证-总结"五段式整理成知识库条目
- 检索内部知识库关于 `{问题}` 的所有历史案例，按相似度排序

### 1.7 办公效率
- 把这份 `{N}` 页的 `{文档类型}` 浓缩成 1 页摘要，给 `{角色}` 看
- 根据 `{会议纪要}`，生成行动项清单（责任人/截止时间/交付物）
- 把 `{邮件}` 转成正式回复，语气：专业但不冷漠

### 1.8 供应链
- 监控 `{物料}` 近30天市场价波动，触发条件：偏离均值 ±5%
- 根据历史采购数据，预测 `{物料}` 下季度需求量
- 供应商 `{名称}` 资质证书自动核查（营业执照/ISO/特许经营）

### 1.9 人力资源
- 根据这份 `{岗位}` JD，生成 5 道结构化面试题（技术 3 + 行为 2）
- 把员工 `{姓名}` 的绩效自评 + 主管评价，生成发展建议

### 1.10 管理决策
- 这份 `{月报/季报}` 的关键洞察 Top5，按业务影响排序
- 模拟 CFO/CTO/COO 三个视角，分别评价这个 `{决策方案}`

### 1.11 编程辅助
- 帮我写一个 `{需求}` 的 Python 脚本，要求：CLI、有日志、错误友好
- 这段代码 `{贴代码}` 在 `{场景}` 下报错 `{错误}`，定位 + 修复

### 1.12 Browser-Use 自动化
- 每天 9 点访问 `{网站}` 抓取 `{招标/竞品/标准/价格}` 公告，新增的发到 `{邮箱}`
- 监控 `{资质证书续期网站}`，临期 30 天提醒
- 自动登录 `{供应商门户}` 查询订单状态

## 二、行业专属补充

### 2.1 制造业
- `{产品}` 外观缺陷分类：划痕/凹陷/色差/装配错位，给出每类的成因和对策
- 设备 OEE 异常分析：可用率/性能率/合格率分别贡献度

### 2.2 金融业
- `{客户}` 近 3 年交易流水，识别异常模式（反洗钱视角）
- 根据 `{监管文件}` 检查 `{业务流程}` 合规性
- 信贷申请书自动审查：财务真实性/担保有效性/还款能力

### 2.3 医药
- 根据 `{GMP条款}` 检查 `{文档}` 一致性
- 药物相互作用查询：`{药A} + {药B}` 在 `{患者画像}` 下的风险
- 临床试验方案的伦理风险审查

### 2.4 能源/电力
- `{设备}` 状态监测数据异常，给出故障预测
- 根据 `{电网调度规则}` 优化 `{时段}` 发电组合

### 2.5 军工
- 涉密文档自动脱敏（保留语义 + 隐藏敏感字段）
- 装备技术指标对比（己方 vs 标杆）

## 三、Prompt Engineering 速查

### 3.1 五要素法
**角色** + **任务** + **背景** + **约束** + **输出格式**

示例：
> 你是 `{企业}` 的 `{部门}` 资深 `{岗位}`（角色）。请审查这份 `{文档}`（任务），目前正在投标 `{项目}`（背景），重点关注 `{风险点}`，避免 `{禁忌}`（约束），输出 Markdown 表格：风险/位置/严重度/建议（格式）。

### 3.2 思维链触发词
- "请逐步思考"
- "先列假设，再验证"
- "把问题拆成 N 个子问题"

### 3.3 少样本（Few-shot）
给 2-3 个输入输出范例，再让模型处理新输入。

## 四、System Prompt 模板

```
你是 {企业全名} 的 AI 助手。
- 业务范围：{主营业务}
- 部门习惯：{该部门关键术语和工作流}
- 合规边界：{保密/红线，禁止讨论的话题}
- 输出风格：专业、可执行、含数据来源
- 不确定时：明确说"需要进一步确认"，不要编造
```
