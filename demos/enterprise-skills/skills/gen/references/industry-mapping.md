## 行业Top5推荐速查

### 制造业（电气/汽车/电子/食品/纺织）
1. B1 文档合规审查（投标场景通用）
2. D1 外观质检AI（制造业最直观的AI场景）
3. B2 跨文档一致性（大型项目文件包）
4. D2 设备故障诊断（运维刚需）
5. E3 生产排程优化（车间管理刚需）

### 金融（银行/证券/保险）
1. B3 合同智能审批（授信/贷款合同）
2. C2 多知识库权限隔离（金融合规刚需）
3. C3 标准法规智能问答（银保监规定）
4. E4 项目风险预警（信贷风险+市场风险）
5. D3 供应商评估→客户尽调

### 医药（制药/器械/CRO）
1. B1 文档合规（药监局申报、GMP文件）
2. C3 标准法规问答（ICH-GCP/药典）
3. C2 权限隔离（临床数据分级管控）
4. D1 质检AI→药品外观/包装检测
5. B2 跨文档一致性（CTD申报文件）

### 科技/软件
1. E5 AI辅助编程（最直接的效率提升）
2. D4 竞品情报监控（快速迭代行业）
3. E1 多Agent辩论（产品/技术决策）
4. C1 知识库RAG（内部文档/API文档）
5. B3 合同审批（SaaS/企业服务合同）

### 能源（电力/油气/新能源）
1. D2 设备故障诊断（设备密集型行业）
2. B1 文档合规（电力行业招投标）
3. E4 项目风险预警（工程项目管理）
4. D3 供应商评估（设备采购链长）
5. C1 知识库RAG（运行规程/操作手册）

### 军工/航天
1. B2 跨文档一致性（军标文件包最刚需）
2. C2 多知识库权限隔离（保密刚需）
3. B1 文档合规审查（标书+军品报告）
4. D1 外观质检AI（产品外观标准严格）
5. E5 AI辅助编程（内网代码助手刚需）
