# 前夜深度对话指南（D-1 关键方法论）

> 这是九洲电器培训案例中**效果最好的差异化动作**：培训前一晚 1.5-2 小时与企业关键决策者/对接人深度对话，把 `/gen` 生成的通用方案 → 升级为"听上去就是给我们做的"。

---

## 一、什么时候用

- **必做**：央企/国企、董事长/总经理亲自参加、≥50万项目
- **推荐**：行业陌生 / 企业有强保密属性 / 有竞品在场
- **可跳过**：标准化中小企业培训、SaaS 类客户、纯技术团队听众

---

## 二、对话目标（4个）

1. **挖出 3-5 个"内部才知道"的痛点故事**（用于 04-台词.md 的开场Hook）
2. **校准 P0 Demo 的优先级**（哪个 Demo 一上来就要打动他）
3. **识别现场地雷**（哪些话不能说、哪些人是反对派、哪些项目是禁忌）
4. **建立私人信任**（让对方感觉这场培训是为他量身定制）

---

## 三、对话结构（90分钟模板）

### 第1段：暖场 + 业务摸底（15min）
- "您今年最在意的 3 件事是什么？"
- "如果让 AI 帮一个忙，您最想它帮什么？"
- "去年公司哪件事让您最头疼？"（→ 痛点金矿）

### 第2段：价值链扫描（30min）
按 12 节点价值链逐一问，问法不是"你们 X 部门有什么痛点"，而是：

- **研发**："去年新品立项到量产用了多久？卡在哪儿？"
- **采购**："最近一次供应商出问题，是怎么发现的？"
- **质量**："出过最大的质量事故是什么？后来怎么改的？"
- **销售**："销售签的合同最近一次被法务打回是什么原因？"
- **法务**："你们看一份合同平均多久？最累的是哪种？"
- **生产**："产线异常报警，从发现到处理平均多久？"
- **客服**："客户投诉最多的是什么？"
- **知识管理**："新员工上手要多久？老员工的经验怎么传？"
- **办公**："每月哪些报表最浪费时间？"
- **HR**："一个岗位招到合适的人平均要多久？"
- **战略**："您每周看的报告里，哪份最有用？哪份最废话？"

每个回答追问："具体一点，最近一次是什么时候？涉及到谁？损失多少？"

### 第3段：Demo 现场试演（30min）
- 笔记本带上 P0、P1 共 3-4 个 Demo
- 现场跑一遍，让对方点评："这个对你们有用吗？"
- 根据反馈实时调整：换术语、换数据、换案例、换顺序

### 第4段：明日策略对齐（15min）
- "明天来的人都有谁？谁是关键决策人？谁可能反对？"
- "哪些话题碰不得？"（涉密/政治/人事）
- "您希望培训完达到什么效果？" → 落地路径精修
- "我可以引用您今天说的某个故事吗？"（取得 Hook 授权）

## 五、对话技巧

### 5.1 让对方多说
- 你说话占比 ≤ 30%
- 多用"嗯，然后呢？""能再具体一点吗？""那当时您是怎么想的？"
- 沉默是金，不要急着填空

### 5.2 收集"原话"
- 对方说出生动的句子时，立刻记下来
- 第二天直接用对方的原话开场，威力极大
- 例：九洲对话中拿到"投了几百万的标，证书过期被漏看，整个项目就废了" → 第二天 Demo10 直接用这句开场，全场静默

### 5.3 验证假设
- 你 `/gen` 出来的痛点，逐条问："这个准吗？"
- 大概率会被推翻 30-50%，这是正常的
- 重新生成时优先用对话里的真实痛点

### 5.4 处理敏感话题
- 涉密项目 → 不追问，只确认"我们明天不会触碰"
- 内部矛盾 → 不站队，只听
- 业绩压力 → 共情但不评论

---

## 六、对话产出 → 喂回 /gen

对话结束后执行：

```bash
/customize 用前夜对话纪要更新方案
```

`/customize` 会：
1. 读取 `{企业名}-前夜对话纪要.md`
2. 更新 `01-痛点.md`：替换通用痛点为对话里的真实故事
3. 更新 `02-选型.md`：按对话调整后的 Demo 优先级
4. 更新 `04-台词.md`：用对方原话改写开场Hook
5. 更新 `08-讲师Rundown.md`：插入"地雷区"提醒

---

## 七、何时跳过

如果对方拒绝深聊（"我很忙，明天直接讲就行"），不要强求。改为：
- 找个**中层对接人**深聊（往往比老板更有故事）
- 提前看 3 篇该企业的**新闻报道**，找到 1-2 个具体事件作为锚点
- 培训当天**前 30 分钟**到场，与早到的人闲聊"摸底"
