# /gen — 企业AI培训方案一键生成

输入一家企业名称（+ 可选补充信息），输出一套可直接用于现场培训的**完整演示包**。

## 输入

- 企业名称（如"招商银行"、"宁德时代"、"四川九洲电器"）
- 可选：行业、规模、已有IT基础、培训受众、时长、特殊需求

## 输出

```
outputs/{企业名}/
├── 00-画像.md          企业画像（行业/规模/部门/IT基础/行业特征标签）
├── 01-痛点.md          8-15个痛点场景（含行业术语、部门、紧急度）
├── 02-选型.md          Demo评分排序 + 匹配表（P0/P1/P2/P3）
├── 03-日程.md          120分钟版 + 60分钟版演示日程
├── 04-台词.md          每个Demo的开场白 + 过渡话术（用企业真实术语）
├── 05-行动.md          18个月落地路线图（3 Phase）+ KPI
├── 06-query.md         50+条该企业可直接使用的大模型Query示例
├── 07-学员手册.md      培训现场发给学员的操作手册
├── 08-讲师Rundown.md   讲师逐分钟操作指南（含应急预案）
├── 09-部署清单.md      培训前一天的环境检查清单
├── 10-QA-Agent.py      培训现场智能问答Agent（8大类33+问题 + 企业上下文）
├── {企业名}-培训FAQ.md  完整FAQ文档（会后材料）
└── demos/              每个选中Demo的定制化演示脚本+说明
    ├── {demo-id}.py    可运行的Demo脚本（已填入企业数据）
    ├── {demo-id}.md    该Demo的项目说明文档
    └── ...
```

---

## 工作流（6步）

### Step 1: 搜索企业信息 → 生成画像（00-画像.md）

用 WebSearch 采集企业公开信息。生成结构化画像：

```markdown
# {企业名} 画像

## 基本信息
| 维度 | 内容 |
|------|------|
| 全称 | ... |
| 行业/细分 | ... |
| 企业性质 | 央企/国企/民企/外企 |
| 规模/员工数 | ... |
| 主营业务 | 1. ... 2. ... 3. ... |
| 核心部门 | 研发/生产/质量/销售/采购/IT/法务/HR |
| 主要产品线 | ... |
| 竞品企业 | ... |

## 行业特征标签
逐项判定（✅/❌）：
- 投标型业务 / 生产制造 / 质检需求 / 保密要求
- 大量文档 / 供应链管理 / 研发团队 / 合同管理
- 设备运维 / 面向B端 / 金融监管 / 医疗合规

## IT基础评估
- 已有系统：ERP/MES/OA/CRM...
- AI现状：是否已用大模型/用了什么/Dify/私有部署
- 算力情况：GPU型号×数量
- 开发团队：人数/技术栈
```

如果搜不到关键信息，用 AskUserQuestion 补问。

### Step 2: 痛点场景分析（01-痛点.md）

**这是核心步骤。**按企业价值链全面扫描：

```
研发设计 → 采购供应链 → 生产制造 → 质量管理
    ↓           ↓           ↓          ↓
销售投标 → 合同法务 → 交付运维 → 客户服务
    ↓           ↓           ↓          ↓
知识管理 → 办公效率 → 人才培训 → 战略决策
```

每个痛点必须包含：

| 字段 | 要求 |
|------|------|
| 场景名称 | 用行业术语（不是"文档管理"，是"GMP文件一致性检查"） |
| 痛点描述 | 具体到该企业（不是"效率低"，是"一个投标项目上百份文档改一处要改N处"） |
| 涉及部门 | 明确责任部门 |
| 紧急程度 | 🔴高 / 🟡中 / 🟢低 |
| AI解决思路 | 一句话方案 |

目标：8-15 个痛点，每个价值链环节至少考虑 1 个。额外追加 2-3 个"隐藏场景"（企业没意识到但 AI 能创造价值的）。

### Step 3: 评分选Demo（02-选型.md）

从 Demo 武器库（见 `references/demo-catalog.md`）中选择。

**评分方法**：每个 Demo 对每个痛点打 0-3 分：
- 3 = 直接解决   2 = 间接相关   1 = 技术可迁移   0 = 无关

**优先级分配**：
- **P0 必做（≤3个）**：总分最高 + 痛点紧急度🔴
- **P1 强烈推荐（≤5个）**：总分次高
- **P2 建议**：有价值但非急需
- **P3 可选**：远期探索

**行业跳过规则**（见 `references/industry-mapping.md`）

**输出格式**：
```markdown
| 优先级 | Demo | 解决的痛点 | 实现方式 | 难度 | 预期价值 | 定制要点 |
```

### Step 4: 逐Demo生成定制内容（demos/目录）

对每个选中的Demo，生成两个文件：

#### 4a. 演示脚本 `demos/{demo-id}.py`

基于 `references/demo-templates/` 中的模板代码，替换为该企业的真实数据：
- 产品名称、型号、参数
- 部门名称、岗位名称
- 行业标准、法规编号
- 真实的业务场景和术语

脚本必须：
- 支持 `--auto` 无交互运行
- 支持 `--case N` 选择案例
- 有 `stream_print()` 打字机效果
- 开头有完整的中文 docstring
- 结尾有"技术揭秘"段落

#### 4b. 项目说明 `demos/{demo-id}_说明.md`

```markdown
# Demo — {名称}
## 一、业务价值
### 解决什么问题 / 来自该企业的原话（如有）
## 二、Demo 设计
### 落地路径（Phase 1→2→3→4）
## 三、运行方式
```

**关键规则**：
- 用真实术语：不说"你的产品"，说"S13-M-1600/10变压器"
- 用真实数据：不说"某个指标"，说"2025年营收337.5亿"
- 每个Demo必须有落地路径

### Step 5: 生成配套文件

#### 03-日程.md
两个版本：

**120分钟版**（标准3小时培训的下午场）：
```
[T+0:00] 开场Hook（5min）——举手热场 + 痛点共鸣
[T+0:05] 第一讲：趋势（40min）——四阶段 + 三重构 + 角色演进
[T+0:45] 第二讲：场景（45min）——P0 Demo演示
[T+1:30] 休息（10min）
[T+1:40] 第三讲：前沿（40min）——多Agent辩论（学员互动）
[T+2:20] 第四讲：案例（25min）——P1 Demo演示
[T+2:45] 第五讲：Workshop（45min）——学员动手
[T+3:30] 总结+Q&A（15min）——行动卡片
```

**60分钟缩略版**：只保留P0 + 多Agent辩论 + 行动建议

#### 04-台词.md
每个Demo一段开场白，必须用企业场景引入：
```
❌ "下面我们来看文档审查AI"
✅ "九洲去年有一个标，证书日期过期被人漏看，整个项目就废了——
    如果当时有这个工具……"
```

包含：
- 每个Demo的开场台词
- Demo之间的过渡话术
- 应急话术（Demo失败时怎么说）
- 收尾总结话术

#### 05-行动.md
```markdown
## Phase 1（0-3月）— 快速见效
- [具体场景] → [具体Demo] → 预期KPI → 负责部门

## Phase 2（3-6月）— 规模推广
- ...

## Phase 3（6-18月）— 深度智能
- ...

## 投入估算
| 项目 | 预算范围 | 说明 |
```

#### 06-query.md
按部门/岗位分类，50+条该企业可直接使用的大模型Query。
覆盖：投标管理、设计研发、质量管理、合同法务、生产制造、知识管理、办公效率、供应链、人力资源、管理决策、编程辅助、Browser-Use自动化。
每条Query用企业真实的产品名、标准名、部门名。
附：Prompt Engineering 技巧速查 + System Prompt 模板。

#### 07-学员手册.md
培训现场发给学员（可打印A4双面），包含：
- 今日议程
- Wi-Fi/平台访问信息
- 每个动手实验的操作步骤
- 扫码反馈入口
- 课后资源清单

#### 08-讲师Rundown.md
逐分钟操作指南：
```
| 时段 | 累计 | 内容 | Demo | 关键动作 |
```
包含：每个Demo的启动命令、投屏切换提示、互动提问设计、应急预案。

#### 09-部署清单.md
培训前一天的环境检查清单：
- Python/Node版本检查
- API Key配置
- 一键预运行所有Demo
- 网络/投屏/音响测试

#### 10-QA-Agent.py
培训现场智能问答Agent（从模板 `demo_培训QA_Agent.py` 生成）：
- 内置8大类33+高频问题知识库（能力边界/安全合规/成本投入/落地路径/岗位影响/技术选型/具体场景/战略组织）
- 用该企业名称初始化上下文，回答自动结合企业情况
- 支持三种模式：
  - `--auto`：自动演示8个预设问题（适合展示）
  - 交互式：学员现场提问（投屏展示）
  - `--faq`：生成完整FAQ文档（附在会后材料中）
- 先查FAQ精确匹配 → 查不到则LLM生成 → 每个回答附"💡一句话要点"

### Step 6: 自检

生成完毕后逐文件检查：

| 检查项 | 标准 |
|--------|------|
| 企业术语 | 每个文件至少出现3次企业真实产品名/部门名 |
| 痛点具体性 | 不出现"提升效率"等泛泛描述，必须有量化预期 |
| Demo可运行 | 每个.py文件有 `if __name__ == "__main__"` |
| 落地路径 | 每个Demo有 Phase1→2→3 路径 |
| 日程时间 | 加总 = 预期总时长 ± 5分钟 |
| 行动KPI | 每个Phase有具体数字指标 |

不合格的重新生成。
