# /customize — 修改企业培训方案

对 `/gen` 生成的演示包做增删改。

## 定位已有方案

读取 `outputs/{企业名}/00-画像.md` 获取上下文，操作该目录下的文件。
如果用户没说企业名，列出 `outputs/` 下的所有企业让用户选。

## 支持的操作

### 1. 术语替换
> "把金葵花改成钻石客户" / "S13改成S15"

在该企业目录下所有 .md 和 .py 文件中全局替换。展示替换了多少处。

### 2. 深度定制单个Demo
> "标书审查Demo加上军品资质检查" / "合同审批加入保密条款检查"

读取该Demo(.py+.md) → 读取企业画像 → 重新生成更详细的版本 → 写回文件。
同步更新台词文件(04-台词.md)中该Demo的开场白。

### 3. 新增Demo
> "加一个智能催收的Demo" / "加一个设备预测性维护"

从Demo武器库(A-E系列)选择模板 → 用企业术语填充 → 生成.py+.md文件 → 更新：
- 01-痛点.md（追加新痛点）
- 02-选型.md（追加匹配条目）
- 03-日程.md（插入时间段）
- 04-台词.md（追加开场白）

### 4. 删除/跳过Demo
> "删掉质检AI" / "这次不需要排程优化"

在02-选型.md中标注"跳过" → 从03-日程.md中移除 → 不删源文件。

### 5. 切换受众版本
> "改成管理层30分钟版" / "改成技术团队深度版"

按受众重新筛选Demo → 重新生成03-日程.md → 调整内容深度。

受众模板（落地型Demo优先）：
- **决策层(30-60min)**：A1三级能力 + E1多Agent辩论 + 1个P0行业Demo + 行动建议
- **业务人员(2-3h)**：B系列(文档智能) + D系列(专业判断) + Query体验
- **技术团队(2-3h)**：E5编程助手 + C系列(知识库) + 双引擎架构 + Dify实操
- **全员混合(3-3.5h)**：标准版，按评分P0→P1→P2排列

### 6. 行业化补强
> "Demo不够行业化" / "太通用了"

逐文件自检清单：
- [ ] 每个Demo文件出现≥3次企业真实产品名/部门名？
- [ ] 痛点描述有量化数据（不是"效率低"而是"一个标要审3天"）？
- [ ] 模拟数据用的是该行业的真实产品参数？
不达标的重新生成，展示改了什么。

### 7. 追加企业信息
> "我们最近上了新风控系统" / "他们其实有Dify平台"

追加到00-画像.md → 重新评估受影响的Demo → 更新内容 → 展示变更。

### 8. 补充痛点
> "他们还提到设备巡检很头疼" / "加上跨部门协作的问题"

追加到01-痛点.md → 重新匹配Demo → 更新02-选型.md → 可能触发新Demo生成。

### 9. 追加Query
> "给采购部再加几条Query" / "Browser-Use的Query太少了"

在06-query.md对应章节追加，使用企业真实术语。

## 规则

- 每次改完展示diff摘要（改了什么、为什么、影响哪些文件）
- 重要修改前备份为 `.bak`
- 改了Demo内容 → 同步更新 选型/日程/台词/学员手册
- 改了.py脚本 → 确保 `--auto` 模式仍可运行
