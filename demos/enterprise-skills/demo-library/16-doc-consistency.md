## 核心价值主张

GMP 文件、技术规格书、用户手册、合同附件——同一参数（产品型号/版本号/有效期/计量单位）在 N 份文档里写法不一致，是审计/质检/客诉的高频根因。AI 自动找出所有不一致点 + 改名同步建议。

## 通用演示指令（待替换）

```
扫描 {{文档集}}，找出所有 {{关键字段}} 的不一致点：
- 同一对象不同写法（如"S13-M-1600" vs "S13M1600"）
- 同一参数不同数值（如有效期 2025-12-31 vs 2025/12/31）
- 引用关系断链
输出：不一致清单 + 修订建议
```
